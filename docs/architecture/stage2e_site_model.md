# Stage 2E Site Model

The portfolio brief requires approximately six manufacturing sites and 30 production lines.

The enterprise demonstration layer therefore uses six fictional European manufacturing sites with five generic production lines per site.

- Germany: Dortmund
- Netherlands: Rotterdam
- Poland: Wroclaw
- Czechia: Brno
- France: Lyon
- Spain: Zaragoza

The selected geography gives the later weather and energy-price context enough geographic variation without expanding project scope.

Only site identity, country, reference city, coordinates, and generic line identifiers are defined at this stage. Operational values remain source-derived or will be added later only where the Stage 3 synthetic-integration plan explicitly requires them.
