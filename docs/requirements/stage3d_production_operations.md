# Stage 3D Production Operations

## Grain
One row per production line per shift.

## Period
2024-01-01 through 2025-12-31.

## Consistency
Actual output is derived from nominal rate, planned production time, availability, performance and quality drivers. The same retained loss drivers will be used to generate later downtime and quality event records.

## Data classification
All rows are explicitly synthetic operational integration data. They are not presented as measurements from the public beverage dataset.

## Scope boundary
No detailed downtime events, maintenance work orders, telemetry, energy consumption or financial-loss records are generated here.
