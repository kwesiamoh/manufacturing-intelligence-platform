# Install the Velora starter template in Power BI Desktop

## 1. Import the theme

In Power BI Desktop:

**View -> Themes -> Browse for themes**

Choose:

`theme/Velora_Manufacturing_Intelligence_Theme.json`

This applies the Velora colors and basic visual styling.

## 2. Set the report canvas

Select the blank page, then open the Format pane.

Set:
- Canvas/page type: 16:9
- Background: `#F4F6F8`

## 3. Use the layout guide

Open:

`layout/Velora_Executive_Overview_Layout.png`

Use it as the visual reference while we build the page.

You may temporarily use it as a page wallpaper/background while positioning visuals, then remove it or set it fully transparent once the real visuals are in place.

## 4. Branding

Company:
`Velora Beverage Group`

Report:
`Manufacturing Performance & Energy Intelligence`

Page:
`Executive Overview`

## 5. Next

Do not build every visual at once.

After importing the theme and confirming the canvas, we will build:
1. header and filters
2. KPI cards
3. site map
4. technical opportunity chart
5. OEE and energy comparisons
6. executive matrix
7. final spacing and interactions
