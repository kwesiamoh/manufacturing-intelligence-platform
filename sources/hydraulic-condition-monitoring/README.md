# Hydraulic condition-monitoring data

This increment adds a real measured condition-monitoring source for reliability analytics.

## Authoritative dataset

**Condition monitoring of hydraulic systems**  
UCI Machine Learning Repository, dataset ID 447  
DOI: 10.24432/C5CW21  
Creators: Nikolai Helwig, Eliseo Pignanelli, Andreas Schütze  
License: CC BY 4.0

UCI states that the data were experimentally obtained from a hydraulic test rig operated in repeated 60-second load cycles. Raw sensor matrices cover pressure, motor power, flow, temperature, vibration and derived efficiency quantities. Component condition labels cover cooler, valve, pump and accumulator health.

## Important scope note

This is **real measured experimental condition-monitoring data** suitable for
degradation, fault classification, reliability-condition, and anomaly-analysis
modules. Maintenance work orders, labour hours, and spare-parts costs lie
outside its schema and require a separate source.

## Folder layout

- `bronze/hydraulic_condition_monitoring/` — untouched official source after download
- `metadata/` — source provenance, sensor dictionary and condition-label dictionary
- `scripts/download_bronze.py` — downloads the official UCI ZIP and extracts it without altering files
- `scripts/validate_bronze.py` — checks required files and expected cycle structure
- `scripts/bronze_to_silver.py` — writes analytics-ready Parquet while preserving cycle IDs and label semantics
- `silver/reliability/` — generated output location

## Run order

```bash
python scripts/download_bronze.py
python scripts/validate_bronze.py
python scripts/bronze_to_silver.py
```

Install dependencies if required:

```bash
pip install pandas pyarrow requests
```

No synthetic observations are generated by these scripts.
