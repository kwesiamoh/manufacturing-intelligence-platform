# Integration notes

This dataset should remain independent from the operational datasets gathered in Steps 1–11. It provides real annual installation-level/aggregated EU ETS emissions and compliance information, not machine telemetry.

Later Gold outputs may include:
- verified_emissions_by_country_sector_year
- installation_emissions_trend
- sector_emissions_benchmark
- allowance_vs_verified_emissions
- carbon_exposure_reference

Do not calculate product carbon intensity unless a defensible production denominator exists for the same installation and period.
