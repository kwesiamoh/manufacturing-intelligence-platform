# Integration notes

Eurostat publishes non-household electricity and gas prices by country, consumption band, tax treatment
and semester. Preserve those dimensions in Silver.

The portfolio should later select the appropriate country and consumption band for each fictional site
only after the enterprise site model and assumed annual consumption levels are finalized.

For historical cost modelling, use the semester matching the operational date rather than applying the
latest price to all years.

These datasets are benchmark/reference data, not site invoices.
